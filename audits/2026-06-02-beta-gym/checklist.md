# Audit Checklist

## Performance

- [ ] Run PageSpeed on key pages
- [ ] Check mobile score
- [ ] Identify LCP element
- [ ] Check image weight
- [ ] Check font loading
- [ ] Check layout shift

## UX and Conversion

- [ ] Above-fold offer is clear
- [ ] Primary CTA is obvious
- [ ] User can contact/book within 1 click
- [ ] Trust signals are visible
- [ ] Forms are short enough
- [ ] Navigation supports key journey

## SEO

- [ ] Title tags
- [ ] Meta descriptions
- [ ] H1 structure
- [ ] Internal links
- [ ] Image alt text
- [ ] Schema opportunity
- [ ] Local SEO basics
